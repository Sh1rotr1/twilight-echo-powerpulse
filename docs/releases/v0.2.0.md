# 0.2.0

适配 Twilight Echo 1.4.0-perview。

## 变化

- 插件 API 升级到 v4，宿主要求 `>=1.4.0-perview`。
- 标题栏新增“设备电量”按钮，点击打开原生插件面板。
- 面板通过 `contributes.experiences`（bridgeVersion 2，`launch: "panel"`）和 `plugin.request` 调用 `powerpulse.overview`。
- 面板显示所有带电量设备，每 5 秒自动刷新；支持手动“刷新”。
- 充电设备显示 ⚡，低电量百分比和进度条变红。
- 新增 `network` 权限：1.4.0 体验桥把 `plugin.request` 映射到这个权限。
- 设置面板、播放栏按钮保留；设置保存后 5 秒内同步到面板。
- 不再需要 `app.asar` 补丁；`host/` 只保留给 1.3.x。

## 兼容性

- Twilight Echo `1.4.0-perview`
- 插件 API 4
- Windows

## 验证

- 标题栏按钮出现并打开面板
- 面板显示本机电池与蓝牙键盘电量
- 设置面板保存刷新间隔后，面板显示“每 10 秒 刷新”
- 单元测试通过
