# 0.1.1

交互协同与生效性修复。

## 变化

- 侧边栏卡片最多每 5 秒检查一次插件状态与设置；设置保存后最多 5 秒同步到卡片。
- 刷新间隔小于 5 秒时，卡片按设置的间隔刷新（最低 1 秒）。
- 卡片标题右侧显示设备数据的刷新间隔，悬停显示最近更新时间。
- 点击卡片标题立即刷新，刷新期间电池图标有旋转动画。
- 设置面板摘要增加“更新于 HH:MM:SS”，保存后能直接看到最新读取时间。
- 移除“播放栏按钮写入通知中心”开关；播放栏按钮现在始终写入通知，避免关闭后点击没有反馈。
- 首次读取等待上限从 3 秒提高到 4.2 秒，插件刚激活时设置面板不再先显示空数据。
- 移除已废弃的 `powerpulse.list` 命令与导航页残留逻辑。
- 宿主补丁在应用升级后会刷新备份，`--restore` 还原的是当前版本原包，不再回退到旧版本。

## 兼容性

- Twilight Echo 1.3.1-preview
- 插件 API 3
- Windows
- 侧边栏卡片仍需 `host/` 宿主补丁

## 验证

- 单元测试 27 项通过
- 设置保存后侧边栏卡片在 5 秒内更新；关闭“显示本机电池”与低电量阈值会即时反映到卡片
- 本机电池、Razer Viper V4 Pro、BWV4 TKL（蓝牙）三台设备正常显示
- 设置面板首次打开即可读到数据，不再先显示“正在读取”
