# 0.1.0

首个公开版本。

## 功能

- 本机电池：`Win32_Battery` + `root\wmi BatteryStatus`，显示电量、充电/接电状态和剩余时间。
- Razer 2.4G 外设：91 字节 HID Feature Report（class `0x07` / id `0x80`、`0x84`），Razer Viper V4 Pro 实测可用。
- 蓝牙设备：读取 `DEVPKEY_Bluetooth_Battery`，只显示主动上报电量的设备。
- 侧边栏底部设备卡片：显示所有带电量设备、进度条、百分比、充电标记，低电量变红；跟随宿主主题。
- 设置面板：刷新间隔（1 秒–5 分钟）、显示本机电池、低电量阈值、播放栏通知开关。
- 播放栏按钮：把当前设备电量摘要写入“任务与通知”。

## 安装

1. 扩展中心 → 从文件安装 → 选择 `com.sh1rotr1.powerpulse-0.1.0.tep`
2. 启用插件
3. 侧边栏卡片需要 `host/` 宿主补丁，见仓库的 `host/README.md`

## 说明

- 仅支持 Windows。
- 侧边栏卡片是宿主补丁，`.tep` 本身不修改应用文件。
- 当前内置 Razer 协议；其它厂商的 2.4G 设备需要后续补协议表。
- Razer 键盘在 USB/2.4G 下的 91 字节接口目前只返回遥测，蓝牙模式走 GATT。
